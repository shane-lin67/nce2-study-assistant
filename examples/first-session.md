# 第一次练习与中途暂停

以下是操作示例，不表示你已经完成过任何任务。

## 今天只有 15 分钟

1. 启动页面，查看最早未完成任务。
2. 如果还在听力阶段，先不看原文，听一遍，只说出人物、地点和冲突。
3. 在笔记里写出你真实听到的内容和不确定的地方。
4. 只勾选确实做完的任务。时间到了先暂停，下次继续，不必硬做完整个两小时。

## 向有本地权限的 AI 助手汇报

> 我听了两遍，大致知道发生了争执，但还没听清为什么。我只做了第一项，用时不确定。请保存原话，不要把听力整阶段标为完成。

助手应先读取当前进度，记录明确事实；用时不清楚就不填写。不能因为“听过两遍”就勾完四项任务。

## 暂停后继续

页面暂停后再离开。使用本地命令也可以暂停计时：

```sh
python3 assistant.py pause
```

下次先查看状态：

```sh
python3 assistant.py status
```

`status` 用于读取状态，不要为了演示随意执行 `report --status done`。学习记录与示例应分开保存。
