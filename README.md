# 新概念英语二册 · 两小时学习助手

这是一个本地学习计时与进度助手，为“听力 → 精读 → 跟读 → 复述 → 复盘”的完整学习循环设计。它解决的是学习计划容易中断、完成情况难以追踪的问题。

Lesson 1《A Private Conversation》已可使用。五阶段共 120 分钟：听力 20、精读 35、跟读 25、复述 25、复盘 15。时间是学习预算，可暂停、超时或分两次完成。

## 打开

双击本文件夹里的 `启动学习助手.command`，浏览器会打开 `http://127.0.0.1:8766`。保留启动终端；关闭终端会停止服务，下次双击可以继续。只需本机已有的 Python 3，不需安装依赖、账号或联网。

也可以在本文件夹运行：

```sh
python3 assistant.py serve --open
```

如果 8766 被其他程序占用，用 `python3 assistant.py serve --port 8768 --open`。

## 第一轮怎么学

1. 当前阶段为听力，先保持课文折叠。点“开始计时”，再点“从课文开始播放”。
2. 第一遍只抓人物、地点和冲突；在学习记录中写下理解。完成一项勾一项。
3. 后续按页面四个小任务推进；卡住时选择“卡住了，需要调整”，写清问题并提交。
4. 做完某阶段全部任务，可勾选完四项，或选择“本阶段任务已全部完成”并汇报。右栏随即显示下一步。
5. 五阶段完成后，本课到 100%。在复盘笔记里记录明天的 10 分钟复习时间。

原声支持原速 / 慢速、回退、逐句播放；精读提供课文、中文释义、用法解释、词组、练习和折叠答案。复述先用关键词，再隐藏提示。录音用手机或系统录音工具；本版不做录音识别或自动发音评分。

## 向 Codex 汇报

你可以直接在当前对话说：

- “Lesson 1 听力完成，用了 20 分钟，还听不清 pay any attention。”
- “精读做完前两项，第三项卡住了。”
- “今天先学到这，保留进度。”
- “我回来了，继续 Lesson 1。”

Codex 会读取同一份进度文件，记录你明确汇报的完成情况，回复完成度、卡点和下一项具体行动。没有明确说完成的任务不会自动勾选。“做完前两项”只勾前两项；“听了三遍”仅记录事实，不能推定听力整阶段完成。

网页中的自由文字作为学习记录保存；网页根据你选择的阶段状态、已勾选任务和卡住状态推荐下一步。自由表述的理解与作文批改由当前 Codex 对话处理，网页不接外部大模型服务。

## 记录在哪里

- `data/progress.json`：页面和对话共用的进度真源，包含勾选项、笔记、掌握度、用时与历次汇报。
- `data/学习进度.md`：自动生成的可读快照。计时运行期间最多滞后一个心跳周期，以 `status` 输出为准。
- `lesson-01.json`：课程内容与五阶段任务，可以据此扩展下一课。
- 页面右上角“导出进度”可以额外备份 JSON。不要直接覆盖已有进度文件。

完成度按已勾选任务的计划分钟加权；用时单独记录，不代表掌握度。掌握度为你自评的 1–5 分。汇报分钟填写**当前阶段累计用时**，与计时记录取较大值，避免重复加算。复盘中的明日计划只是记录，不会创建定时通知。

配套 AI 工作流见 [`skills/nce2-study-coach`](skills/nce2-study-coach/SKILL.md)。

计时每 10 秒保存心跳。切换阶段时先暂停；正常离开页面会请求暂停。浏览器异常退出或电脑长时间休眠，45 秒没有心跳后，会在下次读取时将计时退回最后心跳，避免把离开时间计入；可能少计最后几秒，可用阶段累计分钟校正。

## 对话操作接口

在此目录执行 `python3 assistant.py status` 查看进度和下一步；`python3 assistant.py pause` 暂停正在运行的计时。示例：

```sh
python3 assistant.py report --stage listening --status done --minutes 20 --note '听力任务已完成，pay any attention 仍需精读核对'
python3 assistant.py task --stage reading --task reading-1
python3 assistant.py report --stage reading --status blocked --note '还没分清 angry 和 angrily'
```

以上命令会**真实修改进度**，仅在用户确实汇报后执行。阶段 ID：`listening`、`reading`、`shadowing`、`retelling`、`review`。每阶段任务 ID 为阶段 ID 加 `-1` 至 `-4`。撤销误勾用 `task ... --undo`；多行笔记用 `report --note-file /绝对路径/笔记.txt`。修改由文件锁串行执行，JSON 采用原子替换，避免页面和对话同时操作造成文件损坏。

## 资料与验证

课文逐句从项目 `NCE2-course-text.md` 核对；音频与时间轴来自已导入的二册美音 MP3 / LRC。`NCE2.md` 为原导入笔记，本助手未原样采用其中不准确的词义。例如 pay attention 应为“注意、理会”，不是“值得注意”。原始资料未修改。

验证命令：`python3 -m unittest discover -s tests -v`。测试使用临时进度目录，不会把你的课标成已学。
